# 🚪 Hostel Entry Exit Management System

A web-based system designed to efficiently manage and track hostel students' entry and exit records. This project replaces traditional manual registers with a digital solution, improving accuracy, security, and ease of access.

---

## 📌 Features

* 📝 Record student entry and exit details
* 🧑‍🎓 Maintain student database
* 🔍 Easy search and retrieval of records
* 📊 Organized and structured data storage
* ⚡ Simple and user-friendly interface
* 🔐 Improves hostel security and monitoring

---

## 🛠️ Tech Stack

| Layer    | Technology |
| -------- | ---------- |
| Frontend | HTML       |
| Backend  | Python     |
| Database | SQL        |

---

## 📂 Project Structure

```
Hostel-Entry-Exit-System/
│
├── frontend/        # HTML files (UI)
├── backend/         # Python scripts (logic)
├── database/        # SQL queries / schema
├── README.md
```

---

## ⚙️ How It Works

1. User enters student details (entry/exit) through the interface
2. Python backend processes the data
3. Data is stored and managed using SQL database
4. Records can be retrieved anytime for monitoring

---

## 🚀 How to Run

1. Clone the repository

   ```bash
   git clone https://github.com/your-username/hostel-entry-exit-system.git
   ```

2. Navigate to project folder

   ```bash
   cd hostel-entry-exit-system
   ```

3. Run the Python backend

   ```bash
   python main.py
   ```

4. Open HTML files in browser
